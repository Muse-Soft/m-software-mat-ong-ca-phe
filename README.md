# Mật ong rừng & cà phê nguyên chất

Trang giới thiệu (landing page) **tĩnh** — trang giới thiệu cho Mật ong rừng & cà phê nguyên chất. Trang được dựng bằng HTML, CSS và JavaScript thuần, không cần bước biên dịch.

> Mọi tên, số điện thoại, địa chỉ và số liệu trên trang đều là **dữ liệu mẫu**. Giá hiển thị là **giá mẫu**. Biểu mẫu (nếu có) chỉ là giao diện minh họa: không gửi dữ liệu đi đâu và không có backend.

**Demo trực tuyến:** https://m-software-mat-ong-ca-phe.genalpha.dev
**Giấy phép:** [MIT](LICENSE) © M-Software

## Cách xem

Mở `index.html` bằng trình duyệt (nhấp đúp, không cần máy chủ), hoặc mở liên kết demo ở trên. Giữ nguyên các tệp cùng thư mục vì liên kết là tương đối.

| Tệp | Nội dung |
|---|---|
| `README.md` | Tài liệu giới thiệu này |
| `dat-mua.css` | Bảng định kiểu |
| `dat-mua.html` | Trang nội dung |
| `dat-mua.js` | JavaScript của trang |
| `index.html` | Trang chính |
| `styles.css` | Bảng định kiểu (toàn bộ giao diện) |

## English

A **static** landing page for Mật ong rừng & cà phê nguyên chất, built with plain HTML, CSS and JavaScript. All names, contact details and figures shown are sample data, displayed prices are sample prices, and any form is interface-only — nothing is submitted and there is no backend.
